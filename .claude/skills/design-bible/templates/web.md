# Web template

Topic id · title — guiding question(s). Group headings become `topic.group`.
Used by design-bible (a new site) and site-survey (an existing one: each topic also gets an as-is page).
Users can add topics; keep the ids stable.

## Identity
- `pitch` · Pitch — In one sentence: what is the site, and who should leave it having done or felt what?
- `audience` · Audience — Who visits, from where (a link, a search, a résumé), on what device, for how long?
- `pillars` · Pillars — Which 3 rules settle every look-and-feel argument? What will the site never do?
- `voice` · Voice — How does it talk (headings, buttons, empty states)? Three words, plus one line it would never write.
- `references` · References — Which 2–3 sites or games is it like, and how is it different from each?

## Foundations
- `color` · Color — What are the roles (background, surface, text, muted, accent, danger…), and which single value fills each?
- `type` · Type — Which families, and which size/weight steps (a scale)? Where does each step get used?
- `spacing` · Spacing & Grid — Which spacing steps? What are the grid, page margins and max widths per tier?
- `shape` · Shape & Depth — Radii, borders, shadows, glows, blur: which few steps?
- `motion` · Motion — Which durations and easings? What animates on enter/exit/hover, and what never does?
- `iconography` · Icons & Imagery — Which icon set or style? How are images framed?

## Components
- `containers` · Containers — Which panel/card/frame kinds exist, and what does each one mean?
- `controls` · Controls — Buttons, links, inputs, tabs: which variants and states (hover, focus, active, disabled)?
- `effects` · Effects — Decorative layers (glass, glow, particles): which exist, where are they allowed, what do they cost?
- `content` · Content Blocks — The repeated content shapes (project card, timeline entry, skill chip…): fields and variants.

## Structure
- `shell` · Shell & Navigation — What's always on screen? How does someone get anywhere in two moves?
- `pages` · Pages & Sections — Which pages or sections exist, and what's each one's job in one line?
- `layouts` · Layouts — Which layout kinds do pages use, and how does each change from mobile to desktop?
- `states` · States — Loading, empty, error, first visit, returning visit: what does each look like?

## Quality
- `responsive` · Responsive — What changes at each tier (mobile <600, tablet ≥600, desktop ≥1024)? What's cut on a phone?
- `accessibility` · Accessibility — Contrast, focus, keyboard, reduced motion, alt text: what's the baseline?
- `performance` · Performance — Load budget, heavy layers (WebGL, video), and what a slow device or no-JS visitor gets.

## Production
- `stack` · Stack & Constraints — Framework, styling system, hosting. What can't change?
- `scope` · Scope — What ships in this rework, and what waits?
